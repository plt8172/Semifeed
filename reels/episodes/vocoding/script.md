# 대본: 보코딩 (예시)

훅: "전화 속 목소리는 상대 목소리가 아니다" (일상 + 의외의 사실)

| 장면 | 나레이션 | 화면 |
| --- | --- | --- |
| hook | 전화로 듣는 상대방 목소리, 사실은 내 폰이 다시 만든 소리예요 | 폰 속 파형이 깨지며 "폰이 다시 만든 소리" 도장 |
| bits | 목소리를 숫자로 바꾸면 1초에 0과 1 64,000칸 | 마이크 → 파형 → 측정 점 → 8칸 이진수 → 카운터 |
| slice | '아'를 확대하면 같은 모양 반복 → 1/50초씩 자름 | 문장 파형에서 확대, 반복 강조, 자르는 선 |
| recipe | 성대 = 떨리는 줄(빠르기·세기), 입·목 = 울림통 | 카드 3장: 빠르기, 세기, 울림통(아/이 포먼트) |
| listen | 받는 폰이 다시 만듦 → 직접 들어 보기 | 레시피가 폰으로 → A/B/C 재생 |
| outro | 1/5, 1/90으로 줄여도 알아듣죠? 이게 보코딩 | 막대가 줄어듦 → "보코딩" |

## 단순화한 부분
- 실제 보코더는 피치·세기·필터 외에 코드북 번호 등을 더 보낸다
- B(GSM)는 엄밀히는 RPE-LTP, C(Codec2)는 정현파 계열 보코더로, 휴대폰 AMR(CELP)과 방식이 조금 다르다
